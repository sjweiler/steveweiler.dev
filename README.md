# steveweiler.dev

Steve Weiler's portfolio site, built with [Astro](https://astro.build/).

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Astro writes the static site to `dist/`.

## Deployment

The site is deployed by Cloudflare Pages from the `main` branch using:

- Build command: `npm run build`
- Build output directory: `dist`
